# cat-greeting

猫ロボ「チャオ」のおしゃべりページ。NFCタグのURLからスマホで開き、ボタンで声を鳴らします。

- 公開URL：https://umepyon.github.io/cat-greeting/
- 5〜11時台：チャオの絵（さわってにゃ）を1回さわると「おはよう → 朝ごはん → いってらっしゃい」
- 15〜20時台：チャオの絵をさわると「おかえり」
- 21〜4時台：チャオの絵をさわると「おやすみ」
- それ以外の時間：待機のチャオだけで、声は出ません（毎日その時間にタッチしてもらうため）
- 5つの声のボタンは、テスト用に `?all=1` を付けたときだけ出ます。NFCタグには、パラメータ無しのURLを書きます。
- ブラウザの決まりで自動再生はできないため、最初に1回タップします。
- 時間帯・順番・表情は `index.html` の `SCHEDULE`、`FACES` で変えられます。確認用に `?hour=7` のように時刻を指定できます。

声（マーレ風、Irodori TTS）と画像の元は非公開リポジトリ umepyon/cat-robot-blender にあります。ここにはページに必要な分だけを置いています。

一橋大学の寮（景明館・中和寮）に置くQR・NFCの仕組みの1つです。まとめた案内は非公開リポジトリ umepyon/keimeikan-room-walkthrough の docs/SERVICES.md にあります。
